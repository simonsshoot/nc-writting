\begin{enumerate}
    \item \textbf{SimulationAgent}:SimulationAgent is responsible for simulating the action that a real agent would take in response to a user query, prompt is \texttt{SIMULATE\_AGENT\_PROMPT}.
    \item \textbf{AnalysisAgent}: AnalysisAgent performs risk analysis and generates new tools if needed. Corresponding prompts are \texttt{RISK\_ANALYSIS\_PROMPT} and \texttt{TOOL\_PLAN\_PROMPT}.
    \item \textbf{FusionAgent}: FusionAgent is responsible for retrieving and optimizing existing tools, prompts are \texttt{TOOL\_SEARCH\_PROMPT} and \texttt{TOOL\_REUSE\_PROMPT}.
    \item \textbf{ExecutorAgent}: ExecutorAgent executes the tool and action in a sandbox environment, prompts are \texttt{SANDBOX\_TOOL\_PROMPT} and \texttt{SANDBOX\_ACTION\_PROMPT}.
    \item \textbf{AuditorAgent}: AuditorAgent audits the tool's security, prompt are \texttt{TOOL\_DOUBT\_PROMPT} for newly generated tools and \texttt{TOOL\_DOUBT\_OPTIMIZE\_PROMPT} for optimized tools, the optimization of tools that fail the audit will be revised, prompt is \texttt{TOOL\_DOUBT\_AUTO\_OPTIMIZE\_PROMPT}, AuditorAgent will also perform a final decision, prompt is \texttt{DOUBT\_DECISION\_PROMPT}.
    \item \textbf{RevisionAgent}: RevisionAgent is responsible for revising the action if the final decision is unsafe, prompt is \texttt{REFINE\_ACTION\_PROMPT}.
\end{enumerate}

Due to the large number of prompts, they are not listed here. The full prompt content is available at: \href{https://github.com/simonsshoot/DEFEND/blob/gemini/prompts/base\_prompts.py}{Detailed Prompts}.
