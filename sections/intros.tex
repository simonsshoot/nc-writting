Building safe and reliable intelligent agents represents a core challenge in the pursuit of Artificial General Intelligence (AGI)~\citep{fang2025comprehensivesurveyselfevolvingai}. In recent years, significant progress has been made in intelligent agents driven primarily by large language models (LLMs)~\citep{gao2025evovlesurvey}. These agents are capable of autonomously managing files, invoking tools, and interacting with their environments, leading to widespread application across various aspects of daily life~\citep{yu2025finmem,yang2024llmpsychology,gur2023webagent}. Nevertheless, the continuous expansion of their capabilities broadens the width for agent security. For instance, a medical agent could misuse permissions to leak patient data~\citep{yuan2024rjudge}, while an autonomous driving agent might misinterpret user instructions and execute dangerous maneuvers~\citep{han2025dme,mao2023driving}. Establishing effective safety mechanisms for LLM-based agents has thus become a pressing imperative.

Although existing defense methods have achieved some results, they generally exhibit limitations in generalization when confronted with unknown and constantly evolving scenarios. Prompt-based methods, such as CoTSafe~\citep{yin2024safeagentbench}, suffer from insufficient reliability as they rely solely on the ambiguous judgments of natural language. Model-based methods~\citep{zhang2024asb} employ specifically trained discriminators, yet their performance is highly dependent on the data distribution. Rule or knowledge-based methods~\citep{xiang2024guardagent,sadhu2024athena} monitor agent actions using predefined safety guidelines drawn from a priori human knowledge, making them difficult to scale in the face of emerging domains. These approaches collectively reveal a core contradiction: existing defense mechanisms are static, while real-world scenarios are dynamic~\citep{shahriar2025survey}.

This contradiction prompts us to re-examine the essence of agent defense from a new perspective. When confronting complex and changing environments, humans possess a crucial capability: the ability to continually abstract and introspect from environmental interactions, thereby refining decision-making strategies and forming transferable, generalized coping mechanisms, rather than merely memorizing known threats. Such a capacity for self-evolution is precisely what static defense frameworks lack~\citep{cai2025building}. Thus, a natural question arises: \emph{Can we construct an agent defense framework centered on self-evolution, one capable of exhibiting adaptability in dynamically changing environments?}

For self-evolving methods, a significant challenge lies in ensuring evolution does not go astray~\citep{shao2025misevovle}. Some works lack careful auditing of newly acquired knowledge, implicitly assuming ``newer is better'', which is often the root cause of misevolution~\citep{shao2025misevovle,han2025alignment}. Our experiments reveal that even when safety constraints are incorporated into tool design, the guardrail tools evolved by an agent may still pose risks—a phenomenon we define as \emph{Vulnerabilities in Guardrail Tools (VGT)}. Safety is not a one-time attribute but a dynamic process requiring ongoing verification~\citep{shahriar2025survey}. Therefore, it is crucial to establish an independent auditing mechanism to evaluate knowledge generated during self-evolution.

We propose EVOLVE framework (\underline{EVO}lving \underline{L}ifelong-learning agent defense \underline{V}ia audited cod\underline{E} tools), the first to combine agent security with agent self-evolution. The core concept of EVOLVE is to treat the defense mechanism itself as a dynamically generated, continuously evolving, and lifelong learning artifact in the form of Python tools, rather than a pre-defined and fixed set of rules. EVOLVE's core consists of four agent components. AnalysisAgent performs in-depth risk analysis on runtime user requests and agent operations by leveraging a lifelong risk knowledge library, and dynamically generates targeted, executable Python guardrail tools to achieve cross-domain defense generalization. FusionAgent retrieves semantically similar existing tools from the tool library and fuses them with new ones, enabling precise reuse and continuous evolution. ExecutorAgent safely executes protection tools and agent operations within a sandboxed environment, providing verifiable execution evidence. Finally, AuditorAgent independently audits the logical integrity and security of each evolved tool and synthesizes signals from all modules to make final security judgment, forming an autonomous closed loop from risk perception and tool evolution to trusted verification.

Extensive experiments across three benchmarks, spanning multiple domains including finance, healthcare, and industry, with four backbone LLMs, demonstrate that EVOLVE consistently outperforms all baselines across every test combination, achieving F1 scores stably between 0.86 and 0.92. In contrast, static baselines exhibit performance fluctuations of up to 20\% across benchmarks, confirming their poor generalization. A tool reuse rate of up to 50\% indicates EVOLVE's ability to continuously optimize itself through interaction, while ablation study confirms each module performs its designated function effectively. Treating defense as evolvable code artifacts, rather than fixed rules or natural language constraints, is the key to bridging the generalization gap in agent security.

By being the first to integrate agent security with agent self-evolution, EVOLVE breaks through the limitations of traditional static defense baselines and demonstrates exceptional defensive capabilities. As a pioneering effort toward unification in the field of agent defense, this framework showcases the potential for achieving universal agent protection and may inspire the development of more broadly applicable agent protection systems.
